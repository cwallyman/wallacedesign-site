01 — Apps

5 live · runs in your browser

  • WD-001Live data

    Next Trains↗

    The next three SEPTA Regional Rail trains between Jefferson and Paoli, with departure, arrival, status and track. Includes a page of current Regional Rail alerts.

    • SEPTA
    • Live API
    • Cloudflare Worker
  • RRC
    WD-005Live data

    Consist Logger↗

    Records which railcars make up every SEPTA Regional Rail train, every minute, building the history SEPTA's own API doesn't keep. Sortable trip table, daily Excel export and an RSS feed.

    • SEPTA
    • Cron
    • D1 database
    • Excel · RSS
  • PC
    WD-0033D

    Point Cloud Viewer↗

    Open LAS, LAZ and text point clouds right in the browser. Measure, filter by classification and inspect points. Files never leave your computer.

    • Potree
    • LAS · LAZ
    • WebGL
  • CVT
    WD-0043D

    Point Cloud Converter↗

    A Windows helper that turns LAS and LAZ scans into Potree point clouds with drag and drop, then opens them in the viewer.

    • Windows
    • PotreeConverter
  • STK
    WD-002Markets

    Stock Scanner↗

    Scans the last 24 hours of news for a ticker and flags catalyst keywords like financing, grants and awards. Uses your own Alpha Vantage key.

    • Alpha Vantage
    • News

04 — About

Wallace Design is a one-person workshop for useful software. Most of these apps started as something I needed myself: a faster way to check the next train home, a record of which cars ran on which trip, a way to open a laser scan without installing anything.

Everything here is free. The web apps run as static pages with small Cloudflare Workers where live data is needed.
